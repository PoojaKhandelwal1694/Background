# Beach View Webpage

This is a simple webpage created using HTML and CSS. The project displays a beach view background image with a heading and a short description. It is designed as a beginner-friendly project to practice basic web development concepts.

## Features

* Beach background image
* Large heading and text
* Simple CSS styling
* Semi-transparent content box
* Easy to understand and modify

## Technologies Used

* HTML
* CSS

## How to Run

1. Download or clone the project.
2. Make sure the image file (`PIC2.jpg`) is in the same folder as the HTML file.
3. Open the HTML file in any web browser.

* Adding background images
* Working with text alignment and font sizes
* Creating a simple webpage layout
